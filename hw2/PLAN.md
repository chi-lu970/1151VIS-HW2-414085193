# HW2 規劃：台灣的地形與降雨

> 狀態：已實作完成。實作時與原規劃的差異記在最後一節。

## 1. 作業要求與對應

| 要求 | 怎麼滿足 |
| --- | --- |
| 以 HW1 為基礎延伸 | 沿用 HW1 的地形圖、長條圖、色階與前處理流程 |
| 要有應用性、更有用的資訊 | 加入 **每月降雨量**，可以查任何地點每個月下多少雨 |
| 用 D3.js 做動態互動 | 圖層切換、月份滑桿與自動播放、滑鼠查詢、長條圖與地圖連動 |

## 2. 主題

HW1 回答「台灣哪裡高、哪裡低」。HW2 加一個問題：**哪裡多雨、什麼時候下？這跟地形有什麼關係？**

只加降雨量一種資料。選它的理由：

- 跟地形的關係最明顯：山擋住季風，迎風面多雨、背風面少雨。
- 有 12 個月的變化，可以做成動畫。冬天雨落在東北部，夏天換到南部和山區，一播就看得出來。

## 3. 新增資料

| 項目 | 內容 |
| --- | --- |
| 來源 | WorldClim 2.1 月降雨量（`prec`），1970–2000 年的 30 年平均，免註冊 |
| 格式 | GeoTIFF，12 個月各一張，可直接用 HW1 已裝好的 rasterio 處理 |
| 處理 | 裁切台灣範圍，重採樣到與 HW1 地形 **完全相同的 200×260 網格**，套用同一個本島遮罩 |

新增一支腳本 `scripts/process_rain.py`，輸出兩個檔案：

- `public/data/rain-grid.json`：12 個月 × 每格降雨量（mm，存整數），估計約 2 MB。
- `public/data/rain-by-band.json`：9 個高程帶在每個月的平均降雨量，數 KB。

頁尾要註明的限制：這是 1970–2000 的長期平均，不是近年實況；資料是由測站內插出來的模型值。

## 4. 畫面設計

維持 HW1 的兩張圖，各自加上互動。

### View 1：地圖（改 `HypsometricMap.vue`）

- **圖層切換**：兩個按鈕「地形」／「降雨」。地形就是 HW1 原圖。
- **降雨圖層**：畫法跟 HW1 一樣用 `d3.contours()` 分層上色，只是把高程門檻換成雨量門檻（例如 0 / 25 / 50 / 100 / 200 / 300 / 400 / 600 mm），顏色用淺黃→藍。12 個月共用同一組門檻，跨月才能比較。
- **月份滑桿**：拖動選 1–12 月，旁邊一個播放鍵，用 `d3.interval` 自動輪播。
- **滑過查詢**：游標移到地圖上，用 `d3.pointer` 換算成網格位置，提示框顯示該點的海拔和當月雨量。
- 海岸線外框在兩個圖層都保留。

### View 2：長條圖（改 `ElevationHistogram.vue`）

- **切到地形時**：跟 HW1 一樣，顯示各高程帶的面積佔比。
- **切到降雨時**：改成顯示各高程帶的當月平均雨量。換月份時長條用 `d3.transition` 平滑伸縮。
- **連動**：游標移到某一條長條，地圖上只亮出那個高度範圍，其他地方變淡。

## 5. D3 用在哪裡

| 功能 | D3 模組 |
| --- | --- |
| 分層上色（地形與降雨） | `d3.contours`、`d3.geoPath`、`d3.scaleThreshold` |
| 長條圖比例尺與座標軸 | `d3.scaleBand`、`d3.scaleLinear`、`d3.axisBottom` |
| 月份自動播放 | `d3.interval` |
| 滑鼠查詢 | `d3.pointer` |
| 長條伸縮動畫 | `d3.transition` |
| 事件綁定 | `d3.select(...).on(...)` |

HW1 的 D3 只負責計算、沒有互動。HW2 的互動和動畫都改由 D3 處理，Vue 只負責版面和元件切分。

## 8. 風險

- **WorldClim 高解析度版的全球檔很大**：先試能不能只讀台灣範圍；不行就用較粗的 2.5 弧分版（約 4.5 km），並在頁面註明。
- **沿海格子對不齊出現空格**：前處理時用最近的有值格補上，只補本島遮罩內的格子。

## 9. 實作結果與原規劃的差異

- **資料解析度**：WorldClim 的全球壓縮檔可以只讀台灣範圍，所以直接用 30 弧秒（約 1 km）版，沒有降級。輸出的 `rain-grid.json` 約 2 MB。
- **雨量門檻**：依實際數值分布改為 0 / 25 / 50 / 100 / 150 / 200 / 300 / 400 / 600 mm，共 9 級。
- **版面**：兩張圖改成左右並排，滑過其中一張時才能同時看到另一張的連動。
- **多做一項**：游標在地圖上移動時，長條圖對應的高程帶會加外框（反向連動）。
- **預設圖層**：打開頁面先顯示降雨圖層的 1 月。
