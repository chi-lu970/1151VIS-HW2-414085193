# 兩張圖怎麼畫的

整體規劃見 [`PLAN.md`](PLAN.md)。Python 離線處理資料，Vue 3 負責版面與共用狀態，D3 負責比例尺、等值線、座標軸、動畫與互動。

## 1. 資料

```
Copernicus GLO-30 DEM → process_dem.py
  ├─ taiwan-dem-grid.json   200×260 高程網格（海洋 = -9999）  → View 1 地形
  └─ elevation-bands.json   各高程帶面積佔比                   → View 2 地形
CHIRPS v3.0 2025 年逐月降雨量 → process_rain.py
  ├─ rain-grid.json         12 個月 × 同一網格的雨量（海洋 = -1） → View 1 降雨
  └─ rain-by-band.json      各高程帶 × 12 個月平均雨量            → View 2 降雨
```

- **找本島**：高度 > 0 為陸地，用連通元件分析取面積最大的一塊，離島自動排除。
- **面積統計**：在較細的網格上計算，每格面積依 `cos(緯度)` 修正。
- **降雨對齊**：降雨資料內插到與地形完全相同的網格、套同一個本島遮罩，第 n 格在兩檔是同一地點。

## 2. 共用設定（`constants.js`）

| | 門檻 | 顏色 |
| --- | --- | --- |
| 地形 | `0 / 100 / 500 / … / 3500` m | 綠 → 黃 → 棕，3500 m 以上亮橘 |
| 降雨 | `0 / 25 / 50 / 100 / 200 / 300 / 500 / 800 / 1200` mm | `d3.schemeYlGnBu`（淺黃 → 深藍） |

兩張圖用同一套色階；12 個月共用同一組雨量門檻，顏色才能跨月比較。

## 3. View 1：地形／降雨地圖（`HypsometricMap.vue`）

**繪圖步驟**

1. **算尺寸**：每格 2.2 px；寬度乘 `cos(平均緯度) ≈ 0.92`，避免台灣被拉寬。
2. **座標轉換**：`d3.geoTransform` 把格子的欄、列乘上 2.2，再用 `d3.geoPath` 轉成 SVG path。
3. **產生色帶**：`d3.contours().thresholds(門檻)(values)` 得到 9 個「值 ≥ 門檻」的多邊形；海洋值極小，自然留白。
4. **疊圖上色**：由低到高依序畫，高的蓋在低的上面，露出的環狀部分就是色帶。
5. **海岸外框**：≥ 0 m 的多邊形再畫一次，只描邊。
6. **圖例**：右側 9 列色塊 + 區間文字。

降雨圖層畫法相同，只換資料、門檻與顏色；每月的等值線第一次用到才算，之後快取。

**互動**

- **播放**：`d3.interval` 每 0.9 秒換下一個月。
- **滑過查詢**：`d3.pointer` 取游標座標 ÷ 2.2 → 格子的列、欄，查出海拔與當月雨量顯示在提示框。
- **高程帶標示**：把「全島、≥ 下限、≥ 上限」三個多邊形接成一條 path，用半透明白色 + `fill-rule: evenodd` 填色，只有選中的高程帶不被蓋住。

## 4. View 2：各高程帶統計（`ElevationHistogram.vue`）

整張圖由 D3 繪製（`select → data → join → transition`）。

**繪圖步驟**

1. **整理資料**：每列 `{ label, value, fill }`；地形模式 `value` 為面積佔比，降雨模式為當月平均雨量，顏色沿用地圖色階。
2. **y 比例尺**：`d3.scaleBand` 把 9 個高程帶由上到下排開。
3. **x 比例尺**：`d3.scaleLinear`，上限 = 最大值 × 1.1。降雨模式取 12 個月中的最大值並固定，播放時才能跨月比較。
4. **座標軸與格線**：`d3.axisBottom` 畫刻度，另一組長刻度當淡色垂直格線；下方加軸標題（「佔本島面積比例（%）」或「當月平均降雨量（mm）」），左上標「海拔高度」。
5. **畫每一列**：左側區間文字、長條、長條右側數值，外加一個透明感應區方便滑鼠觸發。
6. **轉場**：換圖層或月份時，長條寬度、顏色、座標軸在 0.5 秒內平滑變化，數值用 `textTween` 逐格跳動。
7. **註記**：左下角顯示本島總面積或當月全島平均雨量。

## 5. 兩圖連動（`useMapState.js`）

兩張圖讀寫同一份狀態：

| 狀態 | 寫入 | 效果 |
| --- | --- | --- |
| `layer`、`month` | 地圖控制列 | 兩張圖一起換圖層／月份 |
| `activeBand` | 長條圖滑過 | 地圖只亮出該高程帶 |
| `hoverBand` | 地圖滑過 | 長條圖對應列加外框 |

## 6. 限制

- 每格約 1.0 × 1.6 km，海岸線經過平滑；色帶交界不是真正的等高線。
- 降雨為 2025 年單一年份（CHIRPS v3.0，約 5 km），不是長期平均；7 月破紀錄多雨，山區數值不確定性較大。
